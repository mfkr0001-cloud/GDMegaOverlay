# Changelog

## v2.11.1-android.1

- Initial Android ARM64 port candidate for Geometry Dash 2.2081.
- Add a draggable Easy-style floating menu control.
- Add an in-menu close control and software pointer.
- Add touch-to-ImGui input forwarding, two-finger scrolling, and two-finger-tap right-click handling.
- Add Android64 CI packaging and draft prerelease workflow using Geode 5.11.2+ for GD 2.2081.
- Android runtime behavior and compilation still require CI/device verification.
